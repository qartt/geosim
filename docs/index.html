Geofísica que você vê acontecer

Simulações didáticas de seis métodos geofísicos, com parâmetros ajustáveis e fórmulas reais. Um arquivo JavaScript, nenhuma dependência, em português.

Mexa nos parâmetros e veja a resposta

Aprofunde o corpo e a anomalia gravimétrica alarga. Diminua o contraste entre V1 e V2 e a distância crítica foge do arranjo. Suba a permissividade e as hipérboles do georradar fecham.

Coloque no seu site em um minuto

São Web Components: funcionam em HTML puro, WordPress, React, Vue ou qualquer outro lugar que aceite uma tag.

HTML

Carregue o script e use a tag.

<script src="https://cdn.jsdelivr.net/gh/qartt/geosim@1/dist/geosim.min.js"></script>

<geo-sim metodo="seis" controls info></geo-sim>

npm

Importe uma vez; as tags ficam registradas.

npm i geosim-br

import 'geosim-br';
// ou
import { setTexts } from 'geosim-br';

WordPress

Instale o plugin da pasta wordpress/ e use os shortcodes.

[geosim_lab controls="yes"]
[geosim_sismica v2="3000" info="yes"]
[geosim_campo]Título[/geosim_campo]

A física por trás de cada curva

As curvas vêm de modelos diretos simples, os mesmos dos livros-texto. O objetivo é ensinar o comportamento de cada método, não substituir software de processamento ou inversão.

Sísmica de refração

Primeira chegada é o menor entre a onda direta e a refratada.

t = min(x/V1, x/V2 + 2h·cos(ic)/V1)

Gravimetria

Esfera de 40 m de raio, resultado em mGal.

Δg = G·M·z / (x² + z²)^(3/2)

Magnetometria

Esfera magnetizada por indução, perfil no meridiano magnético.

ΔT = R³kF/(3z³) · g(x/z, I)

Georadar

A velocidade depende da permissividade; difratores viram hipérboles.

v = c/√εr · t = 2√(d² + x²)/v

Eletrorresistividade

Pseudosseção dipolo-dipolo com alvo de resistividade e profundidade ajustáveis.

log ρ = fundo(z) ⊕ alvo(ρ, z)

TDEM

O ombro na curva de decaimento aparece mais tarde quanto mais profunda a camada condutiva.

t ∝ σ·μ0·z²
